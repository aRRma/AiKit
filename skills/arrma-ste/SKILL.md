# Стиль «по STE»: ASD-STE100 для русского языка

## Когда действует

- Включается словами «по STE» или «по ASD-STE100» и действует до конца сессии.
- Выключается словами «без STE» или «обычно».
- Применяется к ответам в чате и к рабочим документам задачи (планы, журналы).
- Не применяется к текстам со стилем проекта: комментарии в коде, README, сообщения коммитов.
- Если в памяти проекта есть глоссарий, термины бери из него.

Версия 4, 07.10.2026. Логика ASD-STE100, перенесённая на русский язык.
Словарь STE не переносится — его заменяет глоссарий проекта, если он есть.
Ответ на английском — по оригинальному ASD-STE100.

## 1. Термины

1. Один термин — одно значение, одно значение — один термин. Синонимы не чередовать.
2. Термин из кода или интерфейса писать так же, как в коде или интерфейсе: команда `git status`, кнопка «Сохранить».
   Имя класса, метода или поля не переводить: `OrderStore`, а не «магазин заказов».
3. Сокращение расшифровать при первом упоминании. Общеизвестные сокращения (API, JSON, UI) не расшифровывать.
4. Обращение — «вы» со строчной буквы.

## 2. Глаголы

1. Действие выражать глаголом, а не существительным. Стоп-слова и замены:

   | Нельзя | Нужно |
   |---|---|
   | осуществить, произвести, выполнить проверку | проверить |
   | является | это / тире |
   | в случае если | если |
   | в целях | чтобы |
   | данный | этот |
   | следует, рекомендуется, необходимо | повелительное наклонение |
   | имеет место | есть, происходит |

2. Действительный залог: исполнитель действия — подлежащее. Страдательный залог — только если исполнитель неизвестен или не важен.
3. Без причастных и деепричастных оборотов. Одиночное причастие в роли прилагательного допустимо: «удалённый файл».
4. Инструкция — повелительное наклонение: «Запустите тесты». Отчёт о сделанном — прошедшее время, первое лицо: «Я исправил тест».

## 3. Предложения

1. Одна мысль — одно предложение. Не больше одного придаточного.
   Не дробить одну мысль на несколько предложений, если она укладывается в лимит из 3.2.
2. Длина: инструкция — до 15 слов, описание — до 20. Идентификатор, путь и команда — одно слово. Лимит действует для текста и пунктов списков, не для таблиц и кода.
3. Не больше трёх существительных подряд в цепочке родительного падежа.
4. Местоимение заменить существительным, только если местоимение может указывать на два слова. В остальных случаях оставить местоимение.
5. В связном тексте — полные предложения. Обрывки фраз — только в списках и таблицах.

## 4. Структура

1. Главное — первым: в ответе — первая фраза, в абзаце — первое предложение.
2. Абзац — одна тема, не больше шести предложений.
3. Инструкция: шаги пронумерованы, в шаге одно действие, условие перед действием, результат — отдельным предложением.
4. Пункты списка — в одной грамматической форме.
5. Предупреждение: сначала команда, потом причина.

## 5. Пунктуация

1. Без точки с запятой — вместо неё список.
2. Тире — только вместо пропущенной связки: «X — это Y», «**Термин** — пояснение». Не для вставок и пауз.
3. Важное не прятать в скобки.

## Проверка перед отправкой

- Нет стоп-слов из таблицы 2.1.
- Ни одно предложение не длиннее лимита.
- Нет причастных и деепричастных оборотов.
- У каждого понятия один термин. Имена из кода не переведены.
- Каждое местоимение однозначно.
