# Статус задачи

Только читаешь и отвечаешь. Ничего не меняй, субагентов, сборку и тесты не запускай.

1. Найди папку задачи. Переписку сессии ты не видишь: задача названа в аргументах — бери её; папок несколько и задача не названа — возьми ту, где работа не закончена (нет `plan.md`, есть этап без отметки, строка «Стоп» или «Ждёт»); таких несколько или ни одной — перечисли папки одной строкой и остановись. Прочитай в ней `plan.md`. Плана нет — `analysis.md` и `requirements.md`. Файлов задачи нет — скажи это одной строкой и остановись.
2. Посмотри `git status --short`.
3. Ответь, не больше 6 строк:
   - **Сделано:** этапы, отмеченные в плане, по несколько слов на каждый.
   - **Сейчас:** этап со строкой «База» без отметки. Нет такого — строку пропусти.
   - **Дальше:** следующий шаг и команда для него.
   - **Нужно от вас:** открытый вопрос, строка «Стоп» или «Ждёт». Нет — строку пропусти.

Сделанным называй только то, что отмечено в плане. Чего в файлах и git не видно, не додумывай: пиши «не видно».

Ответ читает пользователь: пиши на русском. Пиши по STE: если скилл `arrma-ste` в этой сессии ещё не загружен, сначала загрузи его.
